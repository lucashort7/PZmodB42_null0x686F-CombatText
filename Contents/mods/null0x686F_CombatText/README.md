# null0x686F Combat Text (Standalone)

High-performance $O(1)$ floating damage numbers, hit markers, and critical hit indicators for Project Zomboid Build 42.

## Features
- Floating damage numbers on melee and ranged hits.
- Critical hit indicators (red text with `!`).
- Zero-GC allocation during combat render ticks.
- Fully configurable colors, font size, and fade speeds.
